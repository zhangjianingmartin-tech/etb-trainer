# Escape the Backrooms Trainer

[简体中文](README.md) | [English](README.en.md) | **日本語** | [한국어](README.ko.md) | [Deutsch](README.de.md) | [Français](README.fr.md) | [Español](README.es.md) | [Русский](README.ru.md) | [Português](README.pt-BR.md)

『Escape the Backrooms』（Steam 1943950、UE 4.27）向けの情報オーバーレイ＋お遊び機能ツールです。Python 標準ライブラリのみで実装されています。外部からゲームのメモリを読み書きし、`UObject::ProcessEvent` に小さなフックを仕掛けて、ゲーム自身の UFunction をゲームスレッド上で呼び出します。

> シングルプレイ、または自分が立てた部屋（事情を知っている友人と）での娯楽と、UE リバースエンジニアリングの学習用です。
> 本プロジェクトは Fancy Games および Steam とは一切関係ありません。自己責任でご利用ください。ゲームのアップデートでオフセットやシグネチャが使えなくなる場合があります。
>
> 注意：画面上のパネルやメッセージは現在、簡体字中国語のみです。

## 機能

**オーバーレイ**（読み取り専用、ゲームを変更しません）
- モンスター、アイテム、出口、落下ゾーン、仲間の位置と距離を画面上に表示。画面外の対象は画面端に方向矢印を表示
- 左上パネル：レベル、座標、スタミナ、最寄りのモンスターまでの距離（15m 以内で赤）、出口とアイテムの一覧
- 右上にレーダー（視点が上、範囲 40m、遠くのモンスターは縁に表示）；仲間一覧：名前、生存/死亡、距離、正気度
- 更新頻度はゲームのフレームレートに追従（30〜144）、パネルに両方のフレームレートを表示
- ゲームが最前面でないときは自動で非表示、ゲーム終了時は自動で終了

## 使い方

1. ゲームを**ウィンドウ**または**ボーダーレスウィンドウ**に設定し（排他フルスクリーンだとオーバーレイが隠れます）、レベルに入ります。
2. 次のどちらか：
   - Releases から `ETB-Trainer.exe` をダウンロードしてダブルクリック（Python 不要）
   - Python 3.10 以上をインストールし、ソースをダウンロードして `启动覆盖层.bat`（「オーバーレイ起動」）をダブルクリック、または `python etb_overlay.py` を実行
3. 終了するときは **End**。憑依、凍結、飛行、スキンなどの変更をすべて元に戻してからフックを外します。

単一ファイルの exe は PyInstaller で作成しているため、ウイルス対策ソフトに誤検知されることがあります。気になる場合はソースから実行してください。

## 仕組み

- 起動時にメインモジュールの実行可能セクションを AOB シグネチャでスキャンし、`GNames`（FNamePool）、`GUObjectArray`、`GWorld` を特定します。その他はすべて UE 4.27 の構造とランタイムのリフレクションで読み取ります。
- `ProcessEvent` の先頭 19 バイトをコードケーブへの `jmp` に書き換えます。コードケーブは現在のスレッドがゲームスレッドかを確認し、`lock cmpxchg` で呼び出しフラグを確保して、外部から書き込まれた呼び出しキューをまとめて実行し、最後に元の先頭命令を実行して戻ります。そのため、ゲーム関数の呼び出しはすべてゲーム自身のメインスレッド上で行われます。
- 立場の判定：ローカルキャラクターの `Actor::Role` が Authority なら `World::NetDriver` でシングルとホストを区別し、AutonomousProxy ならクライアントです。

詳しくは [NOTES.md](NOTES.md)（中国語）を参照してください。

## 互換性

Steam build 24997718 で作成・テストしました。アップデート後に「AOB 没找到」（AOB が見つからない）や「ProcessEvent 开头字节和预期不同」（ProcessEvent の先頭バイトが想定と違う）と表示された場合は、アドレスを特定し直す必要があります。
