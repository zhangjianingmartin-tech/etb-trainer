# Escape the Backrooms Trainer

[简体中文](README.md) | [English](README.en.md) | [日本語](README.ja.md) | **한국어** | [Deutsch](README.de.md) | [Français](README.fr.md) | [Español](README.es.md) | [Русский](README.ru.md) | [Português](README.pt-BR.md)

『Escape the Backrooms』(Steam 1943950, UE 4.27)용 정보 오버레이 + 재미 기능 도구입니다. Python 표준 라이브러리만으로 구현했습니다. 외부에서 게임 메모리를 읽고 쓰며, `UObject::ProcessEvent`에 작은 후크를 걸어 게임 자체의 UFunction을 게임 스레드에서 호출합니다.

> 싱글 플레이 또는 직접 만든 방(사정을 아는 친구들과)에서의 재미와 UE 리버스 엔지니어링 학습 용도로만 사용하세요.
> 이 프로젝트는 Fancy Games 및 Steam과 아무 관련이 없습니다. 사용에 따른 책임은 본인에게 있으며, 게임 업데이트 후 오프셋과 시그니처가 동작하지 않을 수 있습니다.
>
> 참고: 화면의 패널과 메시지는 현재 중국어 간체로만 표시됩니다.

## 기능

**오버레이** (읽기 전용, 게임을 수정하지 않음)
- 몬스터, 아이템, 출구, 낙하 구역, 팀원의 위치와 거리를 화면에 표시하고, 화면 밖 대상은 화면 가장자리에 방향 화살표로 표시
- 왼쪽 위 패널: 레벨, 좌표, 스태미나, 가장 가까운 몬스터까지의 거리(15m 이내면 빨간색), 출구와 아이템 목록
- 오른쪽 위 레이더(시점 기준 위쪽, 범위 40m, 먼 몬스터는 가장자리에 표시); 팀원 목록: 이름, 생존/사망, 거리, 정신력
- 갱신 속도가 게임 프레임 레이트를 따라감(30~144), 패널에 두 프레임 레이트 표시
- 게임이 맨 앞에 있지 않으면 자동으로 숨김, 게임이 종료되면 자동으로 종료

**단축키** (실행 후 역할 자동 판별: 싱글 / 호스트 / 클라이언트)

## 사용법

1. 게임을 **창 모드** 또는 **테두리 없는 창 모드**로 설정하고(전용 전체 화면에서는 오버레이가 가려짐) 레벨에 들어갑니다.
2. 다음 중 하나:
   - Releases에서 `ETB-Trainer.exe`를 받아 더블클릭(Python 불필요)
   - Python 3.10 이상을 설치하고 소스를 받아 `启动覆盖层.bat`("오버레이 시작")을 더블클릭하거나 `python etb_overlay.py` 실행
3. 종료할 때는 **End**를 누르세요. 빙의, 얼리기, 비행, 스킨 등의 변경을 모두 되돌린 다음 후크를 제거합니다.

단일 파일 exe는 PyInstaller로 만들었기 때문에 백신 프로그램에서 오탐지될 수 있습니다. 신경 쓰인다면 소스로 실행하세요.

## 원리

- 시작할 때 메인 모듈의 실행 가능 섹션을 AOB 시그니처로 스캔해 `GNames`(FNamePool), `GUObjectArray`, `GWorld`를 찾습니다. 나머지는 모두 UE 4.27 구조와 런타임 리플렉션으로 읽습니다.
- `ProcessEvent`의 처음 19바이트를 코드 케이브로 가는 `jmp`로 바꿉니다. 코드 케이브는 현재 스레드가 게임 스레드인지 확인하고, `lock cmpxchg`로 호출 플래그를 확보한 뒤, 외부에서 써 넣은 호출 큐를 한꺼번에 실행하고, 마지막으로 원래의 시작 명령을 실행한 뒤 돌아갑니다. 그래서 모든 게임 함수 호출은 게임 자체의 메인 스레드에서 일어납니다.
- 역할 판별: 로컬 캐릭터의 `Actor::Role`이 Authority이면 `World::NetDriver`로 싱글과 호스트를 구분하고, AutonomousProxy이면 클라이언트입니다.

자세한 내용은 [NOTES.md](NOTES.md)(중국어)를 참고하세요.
