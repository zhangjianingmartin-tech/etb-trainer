# Escape the Backrooms Trainer 逃离后室修改器

**简体中文** | [English](README.en.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Deutsch](README.de.md) | [Français](README.fr.md) | [Español](README.es.md) | [Русский](README.ru.md) | [Português](README.pt-BR.md)

《Escape the Backrooms》（Steam 1943950，UE 4.27）的信息覆盖层 + 娱乐功能工具。纯 Python 标准库实现，外部读写游戏内存，通过在 `UObject::ProcessEvent` 上挂一个小钩子，在游戏主线程里调用游戏自己的 UFunction。

> 仅供单人模式或你自己开的房间（和知情的朋友）娱乐、学习 UE 逆向使用。
> 本项目与 Fancy Games、Steam 没有任何关系。使用风险自负；游戏更新后偏移和特征码可能失效。

## 功能

**覆盖层**（只读内存，不修改游戏）
- 画面上标出怪物、道具、出口、坠落区、队友的位置和距离；屏幕外的目标在边缘画方向箭头
- 左上角面板：关卡、坐标、体力、最近的怪物距离（15m 内变红）、出口和道具列表
- 右上角雷达（镜头朝上，40m 范围，远处的怪物钉在边缘）；队友列表：名字、存活/阵亡、距离、理智
- 游戏不在前台时自动隐藏；游戏退出时自动退出

**热键功能**（启动后自动判断身份：单人 / 房主 / 房客）

| 热键 | 房主 / 单人 | 房客 |

| F6 | 冻结 / 解冻所有怪物 | 房客不可用（已隐藏） |
| F7 | 飞行穿墙（空格上升、Ctrl 下降） | 房客不可用（已隐藏） |

| Insert | 传送到最近的出口 | 房客不可用（已隐藏） |
| Delete | 复活自己：在死亡位置重生 | 房客不可用（已隐藏） |
| F11 | 无敌：怪物、摔落、溺水都杀不死你（只对自己生效，队友不受影响） | 房客不可用（已隐藏） |
| F1 | 夜视：提高曝光，去掉暗角、颗粒和色散 | 同左 |
| Alt+1 | 自由镜头：镜头离开身体自由飞（WASD、空格/Ctrl 升降、Shift 加速） | 同左 |
| Alt+2 | 理智锁满 | 同左 |
| Alt+3 | 触发游戏自带的加速 + 体力增益 | 同左 |
| Alt+4 | 超级跳 | 同左 |
| Alt+5 | 穿墙：让服务器关掉你的碰撞 | 房客不可用（已隐藏） |
| Alt+6 | 远程拾取最近的掉落道具 | 同左（取决于房主是否检查距离） |

## 使用

1. 游戏设成**窗口化**或**无边框窗口**（独占全屏会盖住覆盖层），进入关卡。
2. 二选一：
   - 下载 Release 里的 `ETB-Trainer.exe`，双击运行（不需要装 Python）；
   - 或者装 Python 3.10+，下载源码后双击 `启动覆盖层.bat`（或运行 `python etb_overlay.py`）。
3. 退出时按 **End**，会先把附身、冻结、飞行、换肤等改动全部还原，再卸下钩子。

单文件 exe 是 PyInstaller 打包的，可能被杀毒软件误报；介意的话直接用源码运行。

## 文件

| 文件 | 说明 |
|---|---|
| `etb_overlay.py` | 入口：覆盖层窗口、读内存、Actor 分类、世界坐标到屏幕的投影 |
| `etb_trainer.py` | 热键功能，跑在覆盖层进程的后台线程里 |
| `etb_call.py` | ProcessEvent 钩子 + 按反射打包参数的 UFunction 调用器（支持批量） |
| `etb_ue.lua` | Cheat Engine 脚本：AOB 定位 GNames / GObjects / GWorld，附带名字解析、反射、Actor 遍历辅助函数 |
| `NOTES.md` | 逆向笔记：全局对象、指针链、偏移、钩子原理 |
| `FUNCTIONS.md` | 可调用函数清单（精选 + 212 个游戏类、1729 个函数的完整签名） |

## 原理简述

- 启动时在主模块的可执行节里用 AOB 特征码定位 `GNames`（FNamePool）、`GUObjectArray`、`GWorld`，之后的结构全部按 UE 4.27 布局和运行时反射读取。
- `ProcessEvent` 开头 19 字节改成 `jmp` 到一块代码洞。代码洞先检查当前线程是不是游戏主线程，再用 `lock cmpxchg` 抢占调用标志，批量执行外部写进来的调用队列，最后执行原来的开头指令并跳回。所以所有游戏函数调用都发生在游戏自己的主线程里。
- 身份判断：本地角色的 `Actor::Role` 为 Authority 时，看 `World::NetDriver` 区分单人和房主；为 AutonomousProxy 时是房客。

详见 [NOTES.md](NOTES.md)。

## 兼容性

在 Steam build 24997718 上编写和测试。游戏更新后如果启动时提示 “AOB 没找到” 或 “ProcessEvent 开头字节和预期不同”，就需要重新定位。
